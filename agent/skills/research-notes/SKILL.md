# Research into reusable notes

Use the task's existing documentation destination. Fleet setup research belongs
under `agent/fleet/`; project research belongs in that project. Do not create a
second notes tree or automatically write to an external app.

For current tools or technical details, check primary sources and the local
installation. Treat unofficial transcripts as discovery aids; link the original
video and label transcript-derived claims. Distinguish demonstrated behavior,
author-reported behavior, and your own proposed adaptation. State what private
material could not be verified instead of claiming to reconstruct it exactly.

Save the conclusion, actionable implications, direct source links, verification
date, and unresolved gaps. Respect source quotation and summary limits. Avoid
raw transcripts, credentials, speculative feature lists, and duplicate manuals.
Check local document links and report the note's location when done.
