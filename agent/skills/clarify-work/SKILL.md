# Resolve consequential uncertainty

Follow the shared [decision workflow](../../workflows/decisions.md). It defines
context checks, one-way and two-way doors, authorized trials, and the evidence to
provide when a decision needs Mathis. Do not require an approved plan before
implementation that Mathis has already authorized.

For choices about visual feel, use an authorized prototype or real example as
evidence. Research-only requests remain research-only unless prototyping is
authorized. Keep settled choices in the current thread or existing issue; reopen
them only when new evidence changes the decision. Use a specification and
dependent vertical slices only when work spans sessions. Do not add a ticket
system for an ordinary fix.

Follow [delegation](../../workflows/delegation.md) for escalation in divided work:
only the tree's interaction owner initiates questions to Mathis; other agents
report unresolved decisions through their parents and continue independent work.
Handle simple tasks directly in the current conversation.
